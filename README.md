# Hasta-Kala Shop Using GenAI

## Project Overview
Hasta-Kala Shop is an Android application developed to support artisans and small craft sellers by providing a simple digital billing and analytics platform. The application helps users track sales, identify best-selling products, and make data-driven production decisions. It focuses on improving income visibility while reducing unsold inventory through easy-to-use tools.

---

## Features
- Quick sale logging (billing system)  
- Best seller analytics (Pie & Bar charts)  
- Low stock alert system  
- Weekly and monthly income tracking  
- Offline data storage using Room Database  
- Simple icon-based UI for low-literacy users  
- Fast and lightweight performance  

---

## Technologies Used
- Kotlin  
- Android XML / Jetpack Compose UI  
- Room Database  
- MPAndroidChart  
- MVVM Architecture  
- Generative AI Tools  

---

## Tools Used
- Android Studio  
- GitHub  
- Figma

## Objective
To develop a mobile application that empowers artisans and micro-entrepreneurs by enabling them to track sales, understand product demand, reduce dead stock, and improve business decisions through simple data insights.
